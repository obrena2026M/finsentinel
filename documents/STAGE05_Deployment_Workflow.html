STAGE05 · documents/STAGE05_Deployment.md

Every push runs the same gate: lint, type-check, 101 non-browser tests with coverage thresholds, a golden-dataset AI evaluation on the mock gateway, Chromium end-to-end tests and the quality gate.

A version tag re-runs that gate, packages one immutable artefact (source + built web app + SBOM), deploys it to staging on a self-hosted Windows runner and smoke-tests it. A human approval on the GitHub production environment releases the production job, which backs up the database before switching releases and rolls back automatically if the smoke test fails.
